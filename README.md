## Versão 1.0.3

Atualização de teste: para validar o atualizador, incluindo indicador de conexão por cores e arcos animados quando conectado. A primeira instalação é manual; as próximas atualizações podem ser consultadas em **Sistema → Atualizações**. Windows prepara a instalação para a próxima inicialização; Android solicita confirmação pelo instalador do sistema.

Os arquivos da Release são completos: não precisam ser reunidos a partir de partes. Baixe o `.exe` no Windows ou o `.apk` no Android; o ZIP de código gerado pelo GitHub não é o instalador.

## Antes de instalar ou atualizar

1. Exporte um backup pelo aplicativo e guarde a senha/chave da base.
2. No Windows, feche o aplicativo, inclusive na bandeja, e execute o instalador.
3. No Android, abra o APK e confirme a atualização. Se solicitado, autorize a instalação por esse navegador/gerenciador de arquivos.
4. Instale por cima da versão existente, **sem desinstalar nem limpar os dados**. Se o Android exigir desinstalação, interrompa.

A assinatura Android foi conferida em relação à 1.0.0. O instalador Windows não tem assinatura comercial e pode exibir aviso do sistema. Download e integridade foram conferidos; instalação física e sincronização nos aparelhos ainda precisam ser confirmadas.

Este repositório contém somente instaladores públicos. O código-fonte permanece privado. O catálogo identifica os downloads históricos que exigem acesso ao repositório antigo.

Para testar a 1.0.3 a partir da 1.0.2, faça backup e use **Sistema → Atualizações → Verificar agora**, sem baixar manualmente. Confira a versão e os registros após concluir. Esta versão inclui o indicador de conexão por cores e arcos animados; a Demonstração compartilhada fica para outra entrega.
